# Al Balı — Instagram Content Generator

A tool that automatically produces on-brand Instagram posts for a business. The colour palette and logo are sampled from the brand's existing posts, so new content matches the current feed.

## Key features
- **Post image generator** (`post_generator.py`) — 1:1 and 4:5 images with the brand colours and logo
- **Weekly content pack** (`week01.py`) — 7 days of posts plus an HTML page for client approval
- **DM reply templates** (`dm_cavablari.md`)
- **Server notifications** (`server_notify.py`)

## Tech stack
Python · Pillow

## Getting started
```bash
pip install pillow
python post_generator.py --demo
python week01.py
```
